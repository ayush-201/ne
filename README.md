# Customer Support Response Time Visualization

This repository contains a professional Seaborn violinplot visualization depicting the distribution and density of customer support response times across different support channels. This analysis supports executive decision-making and strategic planning for support efficiency.

## Files

- `chart.py`: Python script that generates the violinplot using Seaborn.
- `chart.png`: The resulting chart image (512x512 pixels).

## Usage

Run the script with:

python chart.py

## Make sure you have the required packages installed:
pip install seaborn matplotlib pandas numpy
